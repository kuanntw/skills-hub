# Default investment committee output

Use this structure when the user does not provide another format.

## Executive answers

### 1. Current valuation and EPS

State:

- Current/implied valuation.
- How it is calculated.
- Current net income and share count.
- Current EPS.
- Evidence supporting or contradicting management's valuation.
- Valuation range if one point estimate is not supportable.

### 2. Post-investment valuation and ownership

State:

- New investment.
- Pre-money.
- Post-money.
- Price per share when available.
- New shares issued.
- Investor ownership.
- Founder/existing shareholder dilution.
- Cap-table inconsistencies.

### 3. Execution period, outputs, financial effect, and forward EPS

Use a milestone table:

| Period | Use of funds | Deliverable | KPI | Revenue/cost effect | Evidence |
|---|---:|---|---|---:|---|

Then show base/downside/upside only when the inputs justify scenario analysis.

For each scenario show:

- Revenue.
- Gross margin or operating margin.
- Net income.
- Diluted shares.
- EPS.
- Key assumptions.

### 4. Distance to listing / OTC readiness

Use a readiness table:

| Dimension | Current state | Gap | Gating? | Next milestone |
|---|---|---|---|---|

Then summarize the critical path.

## NDF route fit

State likely route, current rule source, investment-size fit, co-investment structure, and open eligibility questions.

## Red flags

List only material issues that can change valuation, financing structure, execution, governance, or exit feasibility.

## Evidence gaps

List the exact missing documents/data needed to convert assumptions into verified facts.

## Investment committee questions

Prioritize 8-15 questions. Put the most decision-changing questions first.

## Required proposal revisions

Give concrete edits to the investment plan, table, forecast, cap table, valuation section, and milestone section. Avoid generic advice.
